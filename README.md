# CHIC TEC｜繭topia 🥚🐣🐜

**Chick Hatch Incubation Cocoon｜Transient Ephemeral Colony**

DyXis の私書箱（P.O. Box）。
本拠地（ブログ・note など）はそのまま。DyXis の網に加わるための仮の住所を、期間限定でお貸しします。

*Keep your home. Borrow an address.*

---

## しくみ

- 私書箱に貼るのは、札（貼札・`nest.json`）**一枚だけ**。本文は、あなた自身の場所に。
- 札には、名前・一行の自己紹介・本拠地へのリンク・RSS（あれば）を書きます。
- 札は箱の住所のうしろ（例：`…/box/001/nest.json`）に貼られ、地図には箱の住所で載ります。本拠地へは、札の「リンク」から案内します。
- 書き込むのは Curator（世話役）だけ。あなたは GitHub に触らなくてかまいません。
- 札の RSS から、新着が別荘（Commons）の地図に流れます。

## 私書箱の札

| 札 | 意味 |
|---|---|
| 🐣 | 使用中 |
| 🈳 | 空き |
| ↩️ | 転送済み（巣立ち） |

## 会則

**第一条**　私書箱の数には限りがある。期間にも限りがある。ここは住むところではなく、巣立つところである。

### 附則

1. 私書箱に貼るのは札一枚。名前・自己紹介・本拠地のリンク・RSS のほかは置かない。
2. 巣立つときは、旧い私書箱に転送札（↩️）を残す。転送先を書くかどうかは、本人が決める。
3. 札を外してほしいときは、いつでも申し出てよい。ただし GitHub はこれまでの書き込みを履歴に残すため、過去の記録からまで消すことはできない。
4. この施設は写してよい。写した施設も、どっかでつながっとく。
5. すでに自分の巣（立札 nest.json を立てた場所）がある人は、私書箱は要らない。自分の巣に立札を立てたら、それが巣立ちの日。巣立つ・外すの届けを出すこと。
6. 私書箱を貸す期間は、札を貼った日から6か月。申し出があれば、一度だけ3か月延ばせる。
7. 期限の日付は、私書箱の札と申し込みの Issue に書いておく。期限が来たら、札を外して空室に戻す（延長の申し出がなければ）。

## 申し込み

- 巣立つ・外す：[Issues で知らせる](https://github.com/ittekiou/CHIC-TEC/issues/new?template=return-box.yml)
